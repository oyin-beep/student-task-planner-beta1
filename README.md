# Part 1: Project Proposal

## App Overview

| Field | Answer |
|---|---|
| **App Name** | TTU Student Planner |
| **App Type** | A calendar, schedule builder, map, groups and event planner designed for Texas Tech University students. |
| **Problem It Solves** | College students have numerous events, assignments, classes, and other commitments to keep track of. Managing all these responsibilities across different platforms can be difficult. Our app aims to bring these commitments together into one centralized platform that helps students organize their academic and social lives. Our target users are Texas Tech University students. |

## Pages and Descriptions

| Page | Name & Description |
|---|---|
| **Page 1** | **Main Page (`student-planner.html`):** Contains the navigation menu, a search bar, and a calendar that reflects items from the schedule page. It serves as the central dashboard for accessing the planner's features. |
| **Page 2** | **Login Page (`login.html`):** Allows returning students to access their accounts through a login form. |
| **Page 3** | **Sign-In Page (`sign-in.html`):** Allows new users to register and create an account by entering their information. |
| **Page 4** | **User Information Page (`student-info.html`):** Contains student details such as their major, clubs, connections, recent events, locations, and academic year. |
| **Page 5** | **Groups and Connections Page (`groups.html`):** Allows users to find and connect with other students and organizations to expand their social and academic networks. |
| **Page 6** | **Schedule Page (`schedule.html`):** Allows users to view and manage their class schedules in a weekly timetable. Students can check class times and locations and organize their academic schedules in one place. |
| **Page 7** | **Events Page (`events.html`):** Allows users to explore sporting events, student events, and student holidays at Texas Tech. It also contains a top section displaying the most recent upcoming events. |
| **Page 8** | **Maps Page (`maps.html`):** Displays an embedded Google Map of the Texas Tech campus. A pin feature helps students identify locations and navigate around campus. |

## Key Interactive Features

| Feature | Description |
|---|---|
| **Key Interactive Feature 1: Search and Student Information Forms** | **Main Page (`student-planner.html`):** A search bar allows users to search for planner information or specific items. **User Information Page (`student-info.html`):** Forms allow students to enter and update details such as their name, TTU email, and other student information. |
| **Key Interactive Feature 2: Schedule Management** | **Schedule Page (`schedule.html`):** Clicking "Add Schedule" opens a pop-up where users can select a date, time, and subject. Clicking "Add Subject" allows users to enter and add a new subject. Clicking the color bar in front of each subject changes its color. Clicking "Click here to add" allows users to add to-do tasks for each subject. |
| **Key Interactive Feature 3: Event Browsing** | **Events Page (`events.html`):** Scrollable sections allow users to browse events from the most recent to those further in the future, helping students discover upcoming activities and plan accordingly. |
| **Key Interactive Feature 4: Groups and Organizations** | **Groups Page (`groups.html`):** Study group and organization categories display different options for students, allowing them to explore groups and find opportunities to connect with others. |
| **Key Interactive Feature 5: Interactive Campus Map** | **Maps Page (`maps.html`):** An embedded Google Map allows users to drag, move, and zoom in or out to explore the Texas Tech campus and locate important destinations using map pins. |

# Part 2: Required File Structure on GitHub

Our project is divided into multiple HTML files, an external CSS stylesheet, and an images folder. This structure keeps the code organized and allows each team member to work on their assigned pages.

Each team member will include an HTML comment at the top of their assigned HTML file identifying their work.


## Table 2: File Structure

| File / Folder | What Goes Here |
|---|---|
| `student-planner.html` | Main student planner dashboard (Page 1). |
| `login.html` | Login page (Page 2). |
| `sign-in.html` | Sign-in and registration page (Page 3). |
| `student-info.html` | User information and profile page (Page 4). |
| `groups.html` | Groups and connections page (Page 5). |
| `schedule.html` | Weekly class schedule and schedule management (Page 6). |
| `events.html` | Sporting events, student events, and holidays (Page 7). |
| `maps.html` | Embedded campus map and location pins (Page 8). |
| `css/styles.css` | All website styling, including layouts, colors, typography, Flexbox, Grid, and responsive design. This must be an external stylesheet. |
| `images/` | Folder containing all image, logo, and icon assets used throughout the project. |
| `README.md` | Project documentation, proposal, file structure, technologies, and individual team contributions. |
